#### Things I've shipped

- [jobreif.de](https://jobreif.de) turns any job posting into an interactive hiring test. LLM-powered PWA with Claude, OpenAI, DeepSeek or local models, hosted with a free quota or run with your own key. Cloudflare Workers backend, vanilla JS, no build step. [Source](https://github.com/qudiqudi/jobreif)
- [hubi.work](https://hubi.work) is a PWA time tracker with E2E-encrypted sync across devices (AES-256-GCM, 12-word seed phrase). Vanilla JS, zero npm deps, Cloudflare Workers + KV backend. [Source](https://github.com/qudiqudi/hubi-work)
- [YAPP](https://qudiqudi.github.io/yapp/) plans ZFS pools: vdev safety math (MTBF / URE / resilver time), live prices from seven retailers, side-by-side comparison of pool variants. Zero dependencies. [Source](https://github.com/qudiqudi/yapp)
- [Grafana finance playbook](https://qudiqudi.github.io/grafana-playbook-finance/) is a runnable Grafana, Postgres and Prometheus stack with seeded finance data, four dashboards and a written guide to metrics, dashboard design and alerting. [Source](https://github.com/qudiqudi/grafana-playbook-finance)
- [marax-shot-timer](https://github.com/qudiqudi/marax-shot-timer) sends Lelit MaraX espresso machine telemetry over WiFi to InfluxDB.

Upstream, I have fixes merged into [smfc](https://github.com/petersulyok/smfc) (Supermicro fan control) and [immich-animals](https://github.com/rtp4jc/immich-animals) (animal recognition for Immich).
